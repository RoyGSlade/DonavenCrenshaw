# Task: "midnight metal" track skin for Stardust's 2D weekly lane (headless, unattended)

Worktree: ~/Desktop/DonavenCrenshaw-skin, branch claude/stardust-track-skin, from origin/main c9dce79 (the live game). The owner loved this look and wants it as the new track skin.

## Reference
`.design-ref/`:
- track-a-0.png, track-b-0.png, track-c-0.png: Meshy renders of the target look
- cockpit-*.png: the same look in context under a glass HUD

The look:
- **Lane:** dark brushed gunmetal deck plates (about #2A2F35 to #4A525B with fine horizontal brushing), etched plate seams across and along the lane, small rivets/fasteners and recessed service-hatch rectangles here and there. A faint diagonal specular sheen.
- **Edges:** each lane edge has a thin recessed cyan neon strip (#3DF2FF core, dashed into long segments like the renders), throwing a soft cyan underglow outward onto the black space.
- **Wet midnight:** very faint short diagonal rain-streak highlights on the plates. Static is fine; a slow shimmer only if cheap. Off under reduced motion.
- **Space around:** near-black with a few faint stars.
- **Pieces:** keep shards cyan and glowing, and mines readable. The start/finish checker is white and charcoal.

## How
- Find where the 2D weekly lane, rails and background are drawn: start with gfx/weeklyVfx.js, ui/graphics.js and engine/track.js; the weekly layout comes from engine/weekly/layout.js.
- **Visual only.** Don't change anything that affects gameplay, collisions, hulls, the sim, replays, timing, the run guard, the hub or leaderboards. If a drawing function lives in a sim file, wrap it from the gfx side instead of editing the sim.
- **Performance is the bar (phones).** The lane is static per track, so pre-render the plates, seams, fasteners and neon to an offscreen canvas once per track and zoom level bucket, then blit each frame. Only cheap animation per frame.
  - Watch memory: tile the cache into chunks if the track is large; no single canvas bigger than 4096 px on a side.
  - Use the existing quality/reduced-motion settings if there are any.
- Make the new skin the default, keep the old one reachable with `?skin=classic` so the owner can compare, and put both behind one small module (e.g. gfx/trackSkin.js).
- No new network requests, no outside assets. Drawing is procedural canvas; small generated textures are fine if built at runtime.
