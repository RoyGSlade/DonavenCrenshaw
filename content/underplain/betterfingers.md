## What it is for

BetterFingers is intended to help people speak naturally, review a draft, and move usable writing into another application. The intended direction is local speech processing with a review step before text is sent.

## Current truth

As of **2026-07-31**, the feature set is locked and the project is in polishing work toward public alpha. It is **not released**, so this page does not call it stable, verified, deployed, or publicly downloadable.

The repository contains two real tray-state images:

![BetterFingers tray icon showing the active recording state](../../assets/betterfingers/tray-active.png)

![BetterFingers tray icon showing the inactive state](../../assets/betterfingers/tray-inactive.png)

Those images are proof that the assets exist, not proof that the complete workflow is ready for ordinary users.

## Intended versus proven

The intended workflow is: record speech, transcribe it locally, optionally refine the draft, review it, and then place it in the active application. The complete workflow, clean-install path, recovery behavior, compatibility matrix, and network-behavior documentation still need public proof.

The [BetterFingers source repository](https://github.com/RoyGSlade/BetterFingers) is the current source link. No installer or release link is presented here because the current authoritative status is not released.

## Known limitations and missing proof

- Windows is the only platform identified for the current testing direction.
- Performance will depend on the user's hardware, audio setup, and selected local models.
- The recording overlay and review window still need real public screenshots.
- A stranger-friendly installation recording and a complete voice-to-transcription-to-review demonstration are still missing.
- Exact versions, compatibility notes, recovery behavior, and current hashes are not published on this page.
- Do not treat the older release links elsewhere in the repository as evidence that this feature-locked build has shipped.
