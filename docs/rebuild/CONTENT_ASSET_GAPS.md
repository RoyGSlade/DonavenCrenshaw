## Promotion checklist

For every product, collect: exact name and owner, supported status word, reviewed date, tested platforms, privacy/network behavior, source/license link, actual artifact/version/hash, limitations, installation/use/recovery/uninstall proof, and a captioned or transcribed demo. If any item is absent, the product page must say so.
