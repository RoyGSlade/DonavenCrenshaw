    How to publish your track
    1. Get every check above to pass (green), including the test pilot.
    2. Test fly it: it opens the game with ?preview=custom&draft=1, flying this draft from this browser. Nothing is saved.
    3. Set the release time and untick Placeholder.
    4. Copy custom-track.js and paste it over projects/Space-Shooter/tracks/custom-track.js.
    5. Run node --test tests/stardust-custom-track*.test.mjs (they run the same checks and the scripted lap), then the full suite.
    6. Open a PR. Once it's merged and deployed, the hangar and the Stardust page count down to the release time, then open it.

    Changing the layout after people have set times? Bump the board version here and in the hub's rules.json. Full notes: docs/stardust/CUSTOM-TRACK.md.
